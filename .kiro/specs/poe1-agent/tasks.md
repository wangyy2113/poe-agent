# POE1-Agent 实施计划（Tasks）

任务按**可运行、可验证**的增量组织：每完成一个阶段，系统都应能真实跑通一条链路，而不是攒到最后再联调。V1 任务已细化到可直接执行；V2/V3 保留为待细化提纲。

约定：
- 每项标注对应需求编号，形如 `_需求: 2.3, 2.6_`。
- 外部数据源相关任务必须先跑通「少量样本」再放量。
- 涉及数值的实现必须同时补单元测试。

  - favicon 内联为 data URI SVG，避免多一次 404 请求
